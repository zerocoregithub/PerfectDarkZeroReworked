# Source-repository entry point

Read PerfectDarkZeroRecomp-v13/AGENTS.md, its architecture and integration guides.
This root contains separate game and modified SDK source trees. Do not merge their
responsibilities or compile unlinked reference sources through wildcards.

Respect nested dependency AGENTS.md instructions, including SDL's contribution
restrictions. Do not generate or edit SDL code as a drive-by project cleanup.

No proprietary game input/output, saves/configs, credentials, captures or build
outputs may be committed. The SDK includes licensed non-game build/test resources;
do not mistake those for PDZ assets or strip required source/licences blindly.

No authorization to publish/push or create PRs is granted by these instructions.
This staging does not inherit upstream Git history. Use the provenance and source
inventory, not an invented claim of common commit ancestry, when integrating work.
